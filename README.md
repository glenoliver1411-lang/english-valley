# English Valley

Original pixel village English-learning game. No backend, GPT API, or player account is required.

Built with HTML, CSS, JavaScript and Canvas. Open the GitHub Pages deployment to play. Progress is stored in your browser. Export your save from the old site and import it here to transfer progress.

Mobile: use the left joystick to move, right button to interact; select tools below. Water crops each game day and sleep at home to grow them. Three residents have schedules and English conversations.
