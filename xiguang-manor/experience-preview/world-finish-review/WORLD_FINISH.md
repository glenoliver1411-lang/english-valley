## 已完成的画面

**天空与山景**：湖畔、屋顶、窗前、主地图地平线和室内窗外共用已有CC0手绘山体与原创林丘。远、中层岩面分别缓存、着色，山脚有树线与薄雾。微型窗景修正了裁图高度，不再只截到空白山尖。夜晚新增三层透明极光，带折叠的下缘和纵向光线；星星仍独立闪烁，湖面只保留低亮度碎影。

**四时段**：清晨6.8、白天12、黄昏18、夜晚22分别有浅金粉蓝、清亮柔和、粉橘紫、冷蓝月夜。天空、山、水、窗光与近景联动。小屋和糖果屋新增独立清晨底画；家具接受日光和附近灯具的局部暖光。回忆册选择时间立即更新正在观看的风景。手动日出仍是原有连续演出，保留屋顶登梯、太阳位置、花草和湖光过渡。

**流星雨**：保留短像素渐变尾迹、微小发光头、星尘、余辉和特殊曦光流星；加入月落、银岸、浅紫三套共同辐射方向的编排，分别调整速度、尾长和间隔，没有垂直灯串或全屏粗线。

**七类烟花**：圆形爆散、柳枝、心形、五角星、多层爆裂、彗尾、连续小礼花。保留真实升空过程、重力下落、渐隐残光和固定粒子池；新增小范围爆光与破碎水平水纹，没有全屏闪白。回忆册和手动发射继续可用。

**糖果屋**：重绘罐架、菜单板、窗框、柜台、玻璃展示柜、包装台、丝带卷、烤炉、配方书与地毯。糖果有包纸折角和模压厚度；礼盒有顶面、侧面、格槽与蝴蝶结；搅拌盆和烤炉有内壁、金属边与玻璃。配方卡、材料标签、计时条、记忆卡、礼盒拖放区统一精修，原九种配方、制作、收火、兑换和包装逻辑不变。

**小屋**：床框、枕头、沙发、壁炉、书架、窗台和书桌增加接合处、边沿与接地关系。12件可布置家具全部重绘顶面、侧面、厚度与不同材质，包括钢琴琴键、留声机喇叭、玻璃花瓶、藤编猫篮。尺寸、翻转、碰撞和已保存摆放位置完全沿用。三套房间颜色、墙纸、地板和花瓶花种继续可选。

**主地图和UI**：原糖果屋的瓦片、窗箱、台阶和烟囱加细；花朵轮廓分化，栏杆与岸石补明暗。界面统一奶油纸面／紫金边缘、轻微厚度按钮、清晰中文与16px输入字号；减少动态偏好同步到CSS动画。

## 自动演出的实际规则

配置集中在 `src/world-config.js`；运行逻辑在 `src/scene-director.js`。

| 位置／条件 | 行为 |
| --- | --- |
| 第一次夜间湖畔，正常欣赏8秒 | 自动流星雨 |
| 湖畔星雨结束后，安静欣赏24秒 | 自动烟花 |
| 第一次夜间屋顶／窗前，正常欣赏12秒 | 自动烟花；之后可接星雨 |
| 已看过的演出 | 每第4次到访才考虑重播，且距上次至少10分钟；每次观景最多两段 |
| 正在拍照、打开面板、静静欣赏、减少动态或白天 | 不启动自动演出，不消耗安静观看时间 |
| 手动开始／跳过／结束演出、手动换时段 | 本次观景不再自动追播 |

自动星雨结束后不强弹奖励面板；星星糖果仍可自主收下。自动烟花散尽后恢复安静。手动重播没有冷却或真实日期限制。回忆册有「风景自然上演」「月夜极光」独立开关，原低特效、减少动态和音乐开关保留。首次礼物信封与苏醒镜头没有被自动演出插入或打断。

## 存档与性能

原进度仍为 `xiguang-manor-v1`，保持已有字段及迁移策略。自动演出历史、极光／自动偏好单独存于 `xiguang-world-atmosphere-v1`，不混入糖果、剧情、家具、心愿数据。存储禁用或配额不足不会阻止游玩。退出不保存仍按原游戏快照恢复进度；风景偏好属于独立设置。

原主场景432像素宽、女孩32×40四方向行走帧保留；观景画布仍为216逻辑宽／432原生宽。CSS保持像素边缘。山体／材质预渲染复用；极光正常10次/秒更新缓存、低特效4次/秒，减少动态时静帧。烟花最大760／低特效240颗火星；流星与烟花使用固定池。弱设备沿用自动降低特效策略，不启用大面积WebGL滤镜。

## 尚可继续完善的美术边界

- 本轮没有逐帧重画主地图32×40角色；湖畔坐姿仍主要通过原造型和服装色板匹配，尚未为六套衣服逐一增加全部配饰。
- 秘密花园和花海继续沿用已有较细的花木，不在本轮重新替换全部植物或扩张地图。
- 极光为艺术化实时光幕，水面为低成本分段倒影，没有物理水体或实时全场景光照。
- 建筑和家具遵循现有轻俯视像素透视；窄屏两侧树冠仍允许自然出画。
- 浏览器手机视口和WebKit模拟可以检验交互与兼容性，不能替代真实iPhone／安卓设备的GPU、温度与续航验收。

本轮到这里交付，不继续大规模扩图或新增玩法。
