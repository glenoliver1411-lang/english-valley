# 小曦的小屋 · 首轮原画家具接入

四张本轮原创生成PNG保留原文件：`room-source.png`、`furniture-source.png`、`decor-source.png`、`surfaces-source.png`。不是使用几何图形重画房间。作者未另具名，不声明CC0；来源、尺寸、SHA-256见`atlas.json`。没有新增第三方下载或外链。

原房间局部坐标432×850、原家具布置和足迹约束继续使用。887×1774底板等比显示为432×864，镜头底部裁去14世界单位，不拉伸。新地板起始338；中央通道与所有原门口/家具站位保留。高清画布最多2倍，退出恢复原视口尺寸。

固定家具六件分别使用透明PNG：壁炉、写字台、床、沙发、衣柜、书架，按接地点排序；原18件可选家具（12免费、6已存在的付费商品）均用新素材展示。贴地影、角色、家具前后、坐姿及坐垫前沿分层；新图不改家具物品ID和交易价格。

可互动：泡茶、坐下/起身、弹琴、灯具与烛台开关、留声机、花瓶中的真实收藏花束、绿植浇水、猫窝、衣柜、书架、信件、礼物、床铺休息、窗边/屋顶日出。布置、移动、翻转、收起、主题/墙纸/地板和天气保存继续使用旧系统。

花架移除原花头成为独立底座，当前花束的三个花种使用原植物PNG裁片分别显示；不是新花瓶永远固定一种花。蕾丝帘架由原秋千的真实雕花立柱和顶檐裁片支撑，帘布原像素移动形成开/合；烛台另有去掉火焰的透明状态。地板用原画材质镜像准备连续边缘，不用几何代码生成木板。所有这些技术派生都在`tools/prepare-cottage.py`，原图不改写。

运行资源为42个道具/材质/状态裁片及1张底板的无损WebP。逐像素验证与PNG一致（包含alpha）；旧PNG和生成源留在源码，不重复加入离线图。少数相同花头内容在构建时自动去重。

局限：仍用原32×40角色；夜间为分材质明暗、窗玻璃和局部灯光，未专门重绘整套夜景原画，原底板晨光纹理还在。墙纸是窄墙面装饰条；家具碰撞保留原可摆放坐标约束，部分足迹较保守。其余森林/花谷/遗迹主体不在此轮重绘。
