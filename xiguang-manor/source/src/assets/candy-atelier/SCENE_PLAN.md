# 月光糖果工坊 · 本地原画分层

空建筑底板 `room-source.png` 与八件透明工坊道具、九种糖、铜碗及开合礼盒分别生成。原图保留，运行使用逐像素验证的无损WebP。图像工具的输出只作为本项目原创生成资源记录，不冒称第三方CC0。没有商业游戏图片拼贴。

世界坐标仍为432×850；建筑底板按宽度等比例缩放，不压扁纵横比。下部多出的14像素由世界边界裁去。相机使用独立密度租约，物件采用原PNG像素而不是几何家具。

- 地板可走范围：x32–400，y335–807。
- 八件道具的实际图片尺寸、脚部占地、交互站位在`candy-atelier.js`集中配置。
- 家具与人物以落地y坐标排序；脚部碰撞比图像边界窄，人物能从柜台后经过并正确被柜台遮挡。
- 原画底板不含柜台，故不会出现背景复制家具、人物穿越画中柜台的问题。
- 轻触图片时按透明度命中最上层道具；通过8px导航网格找路，站到可达位置后打开原有功能。
- 工坊所有玩法继续使用原`candy-model.js`与`shop`存档字段。8次搅拌、3轮收火、九配方、记忆游戏、三糖包装、服装入口保留。
- UI图标采用同组真实图像。制作过程只合成铜碗和烤炉原图，进度/温度条是交互UI，不替代场景美术。
- 普通操作折叠，柜台前仍保留中央通道。新资源全部由Vite导入，纳入当前Workbox资源图，离线可用。

已知限制：当前铜碗以原图小幅转动反馈，尚无独立糖浆/木勺骨骼层；清晨阳光是原画光照，未制作四张独立工坊时段底图。人物保留原有身份与服装像素密度。
