# 玫瑰门庭 · 可分层主世界样板

正式接入更新：默认庄园改用本区，现为39个实体、41个可达交互站位。四块木质花圃复用原plots，3棵树复用原魔法糖索引；所有独立树/花簇/石块有触摸反馈，石径接回三层遗迹。喷泉触碰增加短暂水纹。下文保留首个35物件样板的制作记录；小屋新PNG方案见`../cottage/SCENE_PLAN.md`。既有独立预览保持原构建。

## 正式资源

- `terrain-source.png`：1024×1536 的纯地形绘画层，统一1.25倍成为1280×1920世界。不含建筑、树木或人物；非合成全场景背景。道路与草边在地形层中，房屋和植物全部独立。
- `architecture.png`、`botanical.png`：各1536×1024的独立透明图集，18个帧。原始生成源保留为 `*-source.png`。技术处理规范alpha、切单元格，并清零完全透明像素的RGB以减小体积；可见像素不重画。树冠白底孔洞做透明选择，少量细边仍需继续精修。
- `architecture-light.png`：从三栋原建筑的窗户区域和暖色像素提取的发光蒙版。夜晚恢复原窗灯色，房身仍受冷色环境光影响，不是复制一栋亮建筑覆盖。
- `atlas.json`：帧矩形、尺寸、源文件哈希与制作说明；`GENERATION.json`：原始制作提示及来源；`rose-court.json`：区域地图、实体物件、碰撞、可达站位与出口。

## 地理与图层

1280×1920；人物出生点650,1010；相机手机竖屏视野约800世界单位宽，跟随加前方留白，支持全景与全景直接点选目的地。不纵横拉伸。

地面depth=-1000 → 由原图alpha压缩投射的接地影 → 局部暖光 → 所有房屋、树木、花簇按脚底Y排序 → 主角/装备/猫咪依各自脚底Y排序 → 少量采集反馈 → UI。

房屋原点均为正面接地中点：住宅310,590；花铺1010,820；工坊280,1330。足迹碰撞是单独地图数据，不以图片边缘决定；上半部屋顶可遮住走到屋后的角色。喷泉930,1300有椭圆足迹，长椅930,1660有窄足迹；花拱门640,1840只阻挡左右立柱，中央真正可以走过。树根禁行、树冠遮挡。没有绘制第二套家具盖住原物件。

35个独立物件，6个真实目的地出入口：高清花铺、现有小屋、现有糖果工坊、现有花园、花海、湖畔观景。当前旧场景进入后，离开会回到门庭的原房门；并非按钮只切静态原画。地图缺少的森林/山顶不会放空传送按钮。

## 玩法与存档

玫瑰、薰衣草、向日葵可采入原 play.flowers 库存；沿用1200毫秒采集间隔、原子事务和原价格，进入花铺可出售/包装/买家具。种植仍在原花园，未用草簇冒充新花圃。长椅可坐下/起身，喷泉可以听一会儿，小猫可抚摸/命名/跟随。

`xiguang-manor-v1` 货币、服装、花朵、家具、宝物和剧情机制不变，旧地图position不接收新世界坐标。可丢失的位置侧档 `xiguang-world-layout-v1` 只存区域版本与x/y，不存任何收益；非法/坏位置回安全出生点。跨建筑场景前同步释放高密度画布，返回再恢复，避免比例残留。

## 动态与边界

花草与树木按不同相位极小幅度摆动，根部锚点不平移；少量喷泉水纹约10Hz（低特效3Hz）；复用原有不同花种的采集效果。光照预览对地形、建筑、植物、阴影、窗灯分别插值，约1.8秒过渡。不是整屏滤镜。减少动态模式停风和水纹，保留清晰原图及交互。

尚未达到全世界最终品质：主角仍是原32×40动画，建筑没有可拆屋顶/门开合帧，植物细边尚需人工精修；四时段没有分别重绘的地形和植物变体；地表尚需转换为草边/道路/岸线过渡图块后扩展无缝区域。森林、花谷、湖岸、果园、山顶及其他室内未在本轮重绘。所有缺口见 `docs/world/WORLD_PLAN.md` 和 `ASSET_REQUESTS.json`。
