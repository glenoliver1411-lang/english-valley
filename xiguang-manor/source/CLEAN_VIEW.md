# 普通游戏页面的净景模式

入口：顶部新增的斜线眼睛按钮；「庄园手记」里也有「关闭全部选项」。

- 庄园主地图、林间花园、晚风花海、小屋、糖果屋和观星／流星雨／日出／烟花使用同一个净景开关。
- 隐藏顶部工具栏、HUD、摇杆、互动按钮、提示、场景菜单和Canvas中的悬浮文字标签。建筑贴图上的店招仍属于风景。
- 画布尺寸、镜头与人物比例不变；环境和演出继续播放。
- 手机双击画面恢复，电脑也可按Esc。隐藏期间轻点空地仍可行走，不触发拾取、星星或功能面板，避免录屏时误操作。
- 兼容Phaser使用的旧式touch/mouse事件，恢复手势不会同时触发一次游戏互动。
- 有面板、开场或家具摆放尚未结束时，先收起当前操作。正常打开新面板时自动恢复界面，避免隐藏面板导致卡住。
- 这是临时显示状态，不写入进度档案；刷新后恢复显示，不修改v1存档或数量、衣服、猫名、家具状态。
- 游戏净景处理网页内的覆盖层，浏览器自带地址栏仍由浏览器控制。

新增：`src/clean-view.js`、`src/clean-view.css`、`src/clean-view-config.js`。

接入：`src/main.js`。新增手机浏览器检查：`tests/clean-view-journey.mjs`。

本轮验证：64项原单元测试通过；Chromium和WebKit检查了320/375/430px工具栏、六类场景净景、Canvas标签、行走、双击／Esc恢复、面板保护、演出持续播放及旧档。WebKit也通过了实际静态构建检查。
