## 玩法与入口

- 新玩家进入可跳过的角色创建，填写昵称、选面容、独立搭配衣裤鞋饰、领养小猫，再进入庄园。旧信件和礼物开场留在手记中，自由回看。
- 顶部手记「我的形象与小猫」、地图「换装与装备」、小屋衣橱均打开同一个编辑器。
- 六种发型、七种发色、四种眼型/六种眼色、眉毛与表情、八类上衣、七类下装、四类鞋、五项可叠加配饰；五个独立命名的穿搭格。
- 七种小猫毛色及眼睛、原生/浅色花纹、耳尖/尾尖小变化、项圈、蝴蝶结/铃铛、名字。四向行走、坐下、睡觉、伸展统一使用同一保存形象。
- 主地图、花园、花海、小屋、花铺、糖果工坊、遗迹统一实时人物和猫咪。湖畔/星空使用当前坐姿；极光去除旧人物后按原长椅木条分层显示当前角色，天空与极光演出不变。
- 保存是先写入成功再切换实时形象；失败留在编辑器，可取消，不修改进度。

## 存档保护

仍只有一个可玩存档 `xiguang-manor-v1`，版本保持1。新增 `identity.version=1`，内含 created、nickname、mode、appearance、presets、cat；猫名沿用原 catName 字段。原衣橱拥有记录、房间实例、宝物、糖果、花朵、许愿、天气/音乐均保留。旧存档默认保留原套装与旧猫，不强制创建角色。

额外的 `xiguang-manor-v1:appearance-recovery` **只备份外观配置**：用于旧正式版再次写入时丢弃未知 identity 字段的情况；所有经济、背包和进度仍以唯一主存档为准，不能选择成第二个角色档案。新版本未知身份版本阻止写入，原导出/导入包含身份与穿搭。

## 实际验证

- 126项 Node 测试通过，其中新增6项身份、迁移、五预设、保存失败、未来版本及旧客户端外观恢复检查。
- Chromium和WebKit在390×844、375×667触摸视口运行实机测试；三套指定搭配各四方向行走、五套预设切换、坐下、小屋衣橱、昵称实时更新、同猫跨六地图、湖畔和极光的独立实时人物。
- Chromium真实旧存档保留七套解锁、家具、糖果、花库存、旧许愿与宝物；模拟旧客户端丢字段仅恢复外观，不倒退后来获得的糖果；模拟 localStorage 写入失败未覆盖原身份；原套装坐姿45帧无闪烁。
- 两个浏览器均用**生产构建**：联网完整缓存 → 关闭整个浏览器 → 浏览器离线且服务器503 → 冷启动 → 首次选择从未在线使用的发型、衣裤、鞋饰与奶牛猫 → 进入小屋、糖果工坊、花铺 → 打开极光 → 再关闭/离线重开核对存档。全部通过，无未捕获页面异常。
- Workbox实际审计：**232个资源，47,953,794字节（45.73MiB），缺失0**。所有动态组件、49个人物部件和7个猫图集均在缓存；原始制作PNG、许可证、历史截图和开发文档不纳入离线包。
- 没有iPhone实体设备测试；WebKit自动化不能验证iOS主屏幕安装、系统存储回收、真实软键盘的所有差异。未编造手机FPS或内存测量。

## 性能边界与发布保护
