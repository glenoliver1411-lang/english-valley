# 极光演出的开始与结束修复

版本：`aurora-sequence-20261114-2`。分支：`fix/aurora-sequence-20261114`。回退点：`rollback/aurora-sequence-20261114`（ea756b3）。本轮修复当前独立极光预览，不覆盖正式版或其他游戏/预览。

上一版把已画有极光的原画作为不透明常驻背景，只有额外微光的强度随时间变化，所以极光本体从打开页面起就存在，也永远不会消失；重播只是重置额外微光。另一个问题是旧演出使用封顶的逐帧时间，低帧率下会把时间线拖长。

本轮增加一张同分辨率的无极光夜景底图，原画作为上层按完整时间线显现。夜景只修补原图极光所在的天空，月亮与紧凑的原有白色星点受到保护，610行以下的山峦、花海、长椅和人物与上传图解码RGB逐像素相同。完整舒展时原画不透明，继续保留其原有细节和形状，没有重画一条新极光。静止模式仍然导出原图像素。

| 时间 | 画面 |
| --- | --- |
| 0～2秒 | 安静夜空，极光尚未出现 |
| 2～12秒 | 原画光幕平滑渐现 |
| 12～56秒 | 完整舒展，轻微光感流动 |
| 56～79秒 | 原画光幕平滑淡出 |
| 79秒以后 | 保持安静星空，不自动重播或跳回庄园 |

时间集中在`src/aurora-sequence.js`。演出时钟使用可见时的实际经过时间，与渲染平滑/降帧计时分开；切后台、查看照片、静止欣赏会暂停。`visibilitychange`与引擎恢复事件重置帧基准，销毁场景时移除监听，返回时不会跳过一大段演出。

菜单“再看一次极光”真正重置整个演出，并修复播放选择未保存、刷新后又回到静止偏好的问题。“跳过演出，直接欣赏”只影响本次观景，不改庄园存档。隐藏界面后，结束不会强制显示控制按钮。`play=1`观看链接可以在本次访问中直接播放（不清除已有静止偏好），仍尊重系统/全局减少动态设置；用户也可以手动重播。

场景仍用720×1280本地图像，保持手机DPR画布与原画构图切换。导出照片、音乐、返回、单存档、原有服装和离线更新机制保留。新夜景同样加入Workbox完整缓存；追加参数`show`和`play`由当前版本缓存路由识别，预览范围仍仅为`/english-valley/xiguang-manor/aurora-art-preview/`。

验证包含114项Node测试；Chromium/WebKit真实Phaser的实际开场时钟、阶段截图、结束后不循环、重播/跳过、重播偏好刷新、减少动态、375×667画布和原存档保护。低帧率模拟验证可见的5秒经过时间不会被压成一帧16毫秒。完整录屏没有seek、剪跳或倍速；截图和记录位于`aurora-original-review/sequence.html`。另完成断网关闭浏览器重开、原尺寸照片、返回及存档检查。实体iPhone帧率未测量。
