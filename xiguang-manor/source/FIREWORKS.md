# 曦光花火

进入星光观景台，点击下方「放烟花」。也可在风景回忆册的「风景回忆」页选择「曦光花火」。

- 默认播放约30秒的编排，从单束升空到多束金色繁花，接续垂柳与心愿花火，最后慢慢散落星火。
- 可以轻点天空，指定想让烟花绽放的位置；或按「点燃一束」。
- 三种样式：金色繁花（带二次星簇绽放）、垂柳流金（长而弯曲的下垂尾迹）、心愿花火（粉金心形）。
- 「自由点放」停止后续自动发射，保留已点燃的烟花；「自动花火秀」重新开始编排。
- 「结束烟花」回到正常观星；退出观景台、拍照、音乐开关及原流星雨功能保留。
- 演出后仍可继续手动点放，喜欢的样式与看过的回忆自动保存。不需要糖果，不限制日期，不要求每天登录。

## 绘制与性能

升空火箭、径向主花、延迟的外围小星簇、阻力与重力形成的弯曲尾迹、少量烟雾均为原创代码绘制。烟花位于云和远山后方。光照变化幅度克制，不使用全屏模糊或 bloom。

固定对象池：最多10枚升空火箭、900个星火粒子、48个二次星簇、18团小烟雾。低特效模式使用最多280个星火、较短尾迹和较少星簇，并保留完整编排。持续慢帧也会自动降低细节。重复点击有短暂发射间隔，不会无限增加对象。结束与切换演出会清理活动烟花。

音乐开启时，爆开声由 Web Audio 轻柔合成，无外部录音，受原音乐开关控制。
