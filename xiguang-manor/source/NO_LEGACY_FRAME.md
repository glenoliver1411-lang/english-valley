# 启动闪回与菜单文字可读性修复

版本：`manor-noflash-20261107-1`。分支`fix/no-legacy-frame`；回退标签`before-no-legacy-frame-20261107`。

- 旧Manor仅保留现有控制器/数据兼容用途。`game.js`在Phaser `init`（先于preload）就隐藏该后台并关闭其全部相机；`backend-render.js`在创建完毕后把旧地图与旧房间容器从显示列表移出。数据引用、碰撞与更新列表保留，子场景恢复`world.setVisible(true)`也无法重新显示旧地图。
- 干净本地浏览器上，上一版只观察到旧后台的空加载帧，未重现用户所见的可见旧地图；本轮因此不只检查启动结束截图，而是钩住真实renderer的每次场景渲染调用，并故意模拟错误的父场景可见性恢复。新实现所有路径旧场景renderer调用均为0。
- 真实上一版正式PWA缓存测试确认：旧worker会忽略`v`参数，继续给该链接返回旧HTML。新入口使用`?build=manor-noflash-20261107-1`绕过旧HTML缓存；新worker认识该参数，更新后该链接也可离线打开。未清缓存或重置存档。
- `pwa-service.js`仅当缓存版本与当前页面代码一致时才报告当前版可离线；发现版本不一致时主动检查worker更新，避免浏览器的更新检查节流。仅下载准备更新，仍由玩家确认保存后刷新，不在编辑/制作时自动更新。
- `style.css`在启动样式中提供菜单关键样式，避免依赖懒加载地图样式才获得按钮颜色。地图、时段、观景按钮统一奶油底`#f4e1c7`、深紫字`#4d3654`，包含显式`-webkit-text-fill-color`、15px字/600字重、至少48px触摸高度；卡片底色更实，长菜单滚动。

验证：104项Node测试；Chromium与Playwright WebKit手机视口逐帧检查完整拆信/跳过、回访/跳过、糖果屋/小屋/花园/花海/湖畔往返、强制旧可见性恢复及375×667缩放；另有Chromium强制Canvas渲染检查。地图与时段菜单已检查浏览器计算颜色和实机截图。

生产构建缓存回归：真实`manor-candy-20261107-1`旧缓存→旧v链接仍返回旧HTML→新build链接取得新HTML→玩家确认更新→保留糖果/猫名等旧进度→完全关闭浏览器→服务器503+浏览器断网重开新build链接→实际完成三轮制糖并保存。没有更改存档或经济模型，也没有新增美术资源。
