`public/lakeside-review/`包含390×844手机视口的月夜、清晨、黄昏三组同机位截图；比较时关闭流星、烟花、漂浮粒子和操作UI，保留静态星空与环境局部光，以检查静态画面本身。另有同一区域的最近邻放大：建筑与树木、山体与林丘、近景花草。

运行：

```bash
# 在 xiguang-manor/source/ 中
npm ci
npm run dev
# 浏览器打开终端显示的地址，再进入 /lakeside-review/
# 游戏：顶部星星 → 去星光观景台

npm run build
npm run preview
# 静态预览同样可进入 /lakeside-review/
```

网页对比页提供拖动分界线、时段选择、原尺寸图与实验版游戏入口。图库是实际游戏截图，不是概念图、渲染效果图或生成式修图。

## 素材与原创工作

实际采用的外部素材仅为karsiori的CC0素材包中的13张图，均已核实具体发布页许可并下载本地。作者、URL、逐文件对应、修改与署名说明见`ASSET_CREDITS.md`。Kenney、dustdfg与Riclmbr候选经过筛选而未整合，不混用平台资源，也未复制教程插图。

新坐姿、猫咪姿态、船屋、长椅、望远镜、蕨叶、鸢尾、林丘、水色、阴影和局部灯光由本项目补绘。没有替换原行走角色或音乐，没有使用收费图片生成API。

## 尚未完善的美术问题

1. 主小屋的手绘纹理与原创小船屋/望远镜仍有进一步统一笔触的空间；本轮用同色板、像素网格与光照方向衔接。
2. 坐姿保留各套衣服的配色，尚未逐套绘制不同的刺绣、包袋和褶皱；其他场景仍使用原服装表。
3. 侧边树冠为取景自然出画，极窄屏幕看到的枝叶数量会减少；房屋、长椅、角色及望远镜始终保留在画内。
4. 两种浏览器内核的手机模拟可核对流程、资源和画面，真实iPhone/低端安卓的GPU、屏幕色彩和耗电仍需本人验收。

不把本轮样板称为全庄园美术完成版；等待这处湖畔通过视觉验收后，再决定是否把标准扩展到其他场景。
