# 手机首屏加载与卡住恢复（2026-11-06）

本轮保留原场景、美术、玩法和v1存档，仅缩短启动的下载与绘图路径，并为加载失败提供恢复入口。

## 优化

- 主图集改为本地无损WebP：268,940 → 73,406字节（减少72.7%）。逐像素校验可见RGBA完全相同；原PNG继续保留，不支持WebP或下载失败时回退PNG。
- V5已替代的13张旧湖畔素材不再阻塞主地图或观星入口，原文件和授权记录保留。
- 不再先绘制随后会被V5覆盖的旧地图和两轮旧细节。原物件、碰撞、交互坐标及角色素材仍按相同逻辑生成。
- 地图与山景的四时段缓存改为按需生成。山体调色按源颜色缓存，不再对大量同色像素重复解析、混色。
- Phaser独立为稳定的内容哈希资源，后续仅更新游戏代码时可复用引擎缓存；图片从JS内嵌改为独立缓存文件。
- 初始HTML直接显示加载卡，之后显示真实图片加载进度。失败自动重试至多2次；慢网或失败时可重新加载，也可选择Canvas兼容模式。所有恢复入口保留浏览器存档。
- 发布脚本保留已发布资源，并补齐前两个版本引用的文件，避免缓存页面引用已被下一次更新删除的脚本。

## 可比实测

同一390×844触屏视口，Chromium；冷缓存，1.6 Mbps下载、150 ms延迟、CPU 4倍减速；本地静态服务开启gzip。计时从导航到可点击的首次信封出现，不包括用户阅读或过场时长。各版本一次可比运行，不能代替每种真实手机和网络。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 到首次可点击信封 | 11,805 ms | 5,860 ms |
| 首屏资源传输体积 | 843,772字节 | 585,849字节 |

首屏资源减少约30.6%，本次模拟环境就绪时间减少约50.4%。复现脚本：`tests/startup-benchmark.mjs`，默认读取4173端口的生产构建。页面初始加载提示直接来自HTML，不必等待引擎下载。

## 文件

- `src/boot*.js`：首屏卡片、集中配置、进度与失败恢复。
- `index.html`、`vite.config.js`：轻量启动入口、内联首屏、独立引擎缓存和资源输出。
- `src/game.js`、`src/art.js`、`src/world-detail.js`：精简初始化、失败重试和兼容渲染入口。
- `src/environment.js`、`src/v5-landscape.js`、`src/v5-assets.js`：按需缓存、等价调色与无损图集。
- `src/sky-scene.js`：停止预载已不使用的旧湖畔图像。
- `tools/stage-release.py`：只安装本游戏，保留旧缓存仍可能引用的版本资源。
- `tests/startup-journey.mjs`：Chrome/WebKit真实下载失败、PNG回退、进度、原进度、糖果屋／观星／照片与Canvas进入。

未使用外部API、代理站点、字体、分析服务或新增第三方素材。没有清理localStorage、改变存档格式或降低像素图质量。

- 完整首次开场及跳过／重播、四时段与自动演出、湖畔照片／许愿／换装／日出及小屏幕回归通过。
