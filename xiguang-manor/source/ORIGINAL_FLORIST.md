## 原画怎样成为游戏

直接加载收到的 1169×1280 原画文件。手机聊天把附件保存为 JPEG；原文件逐字节保留，SHA-256 为 `65894e680b4db173744c68b10af36c483657c911e4f8392a15cfce52109381e0`。没有用 Canvas、Pillow、矩形或重复地砖模仿画面。Pillow 仅用于解码、裁切与编码，numpy 只写入透明遮挡蒙版，所有 RGB 都来自原图。

六张透明裁片分别覆盖柜台、中央花桌、玻璃玫瑰桌、前景花箱、左侧花架与招牌。制作脚本验证：裁片在原位叠回原画，与收到的原画像素完全一致。底图始终保留，不擦除原画家具；一楼可走区域避开家具占地，无需凭空补画地板。

## 第一阶段可玩内容

- 一楼有真实行走区域、家具接地点碰撞和绕行路径；柜台、花桌与玻璃花罩可以点击，角色先走近，再打开对应功能。
- 售花、三花包装、花束出售／收藏／放回小屋、六件装饰购买均沿用原交易和存档代码。空库存可直接前往原花海采花，再返回售卖，没有赠送测试货币或改动经济。
- 前景遮挡按倾斜家具脚线判断；角色经过花桌背后时处于前景下方，前方则完整显示。完全遮挡区域保留轻微角色透出，便于定位。
- 保留角色原衣服与四方向动画，按原画场景尺度显示，增加贴地接触影及轻微暖光色调；没有更换身份。
- 二楼、楼梯与拱形温室保持原画完整可见；上阁楼路线在此阶段关闭，没有空按钮。

## 手机构图

原图不拉伸、不压扁。跟随模式只裁切视野，随角色横向移动欣赏；「看全花铺」显示完整构图，点击「回到身边」继续走动。首次短镜头可通过柜台选择或画面点击结束，减少动态模式直接进入探索。

新花铺单独使用最高 2 倍原生画布密度以保留细节，角色与其他游戏仍使用原逻辑坐标。离开前同步恢复原画布尺寸，防止庄园和其他房间缩放异常；场景反复进入不创建重复原画纹理。原有隐藏界面与双击恢复继续可用，去掉花铺内无法使用的全局按钮。

## 边界

这版只开放一楼。画中二楼及阁楼家具暂为风景，没有楼梯上楼操作。原画是固定日光，不在此轮重新绘制夜景或改变光照。已验证的 WebKit 是浏览器内核模拟，不能替代实体 iPhone 的长时运行及系统主屏幕安装检查。

源码分支 `art/original-florist`；回退标签 `before-original-florist-20261107`。只发布 `florist-original-preview/`，不覆盖正式版、PWA 预览或其他既有试玩目录。

本地构建：`npm ci`，`MANOR_RELEASE=florist-original-20261107-1 npm run build:florist:preview`。裁片重建：`python tools/slice-original-florist.py`（需 Pillow 和 numpy）。所有开发与发布已经在云端进行，玩家只需打开试玩链接。
