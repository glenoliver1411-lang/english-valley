# 湖畔观星样板美术规范

## 基础分析与改造范围

基于V4提交`e7591ab`／正式仓库`69bb138`。原游戏采用Phaser 3、JavaScript、Vite；主画布宽432像素，390×844手机视口下游戏画布为432×824。观景内部使用216×412逻辑坐标与2倍Canvas，因此0.5逻辑单位正好对应1个原生像素。此次不提高逻辑分辨率，不更换主地图镜头、碰撞或角色行走表。

原湖畔的优点是大面积留白星空、月亮与银河对角线、两座小屋和中央背向长椅的稳定构图。主要不足是山体被概括成大块平直多边形；相似叶簇、十字花与草茎重复；建筑纹理细节偏少且材质差异有限；旧角色站立素材直接缩放，脚与座面不衔接；湖水主要依靠横线和整幅压缩倒影，空间线索不足。

本轮只让`SkyScene`的`viewpoint === 'lake'`使用独立美术模块。屋顶、窗前、主地图、秘密花园、花海、小屋内部以及首次开场继续走原绘制路径。

## 统一规范

| 项目 | 标准 |
| --- | --- |
| 像素密度 | 432原生像素宽；远景和近景均落在1个原生像素网格，边缘最近邻采样，不使用照片、矢量贴图或模糊滤镜。 |
| 视角 | 湖畔平视远景，近景保留轻微俯视的地面与长椅；屋顶可见上平面，屋檐、侧壁与台阶形成体积。 |
| 角色比例 | 原小曦身份、发色和桃色发带保留；湖畔坐姿48×68原生像素，和房屋/长椅的像素密度一致，其他场景继续用原角色表。 |
| 主色 | 深蓝紫天空、低饱和蓝紫山脉、冷青绿树叶、粉紫屋顶、奶油暖窗、少量粉白花。四时段色表集中在`lakeside-config.js`。 |
| 主光 | 月亮与太阳位于画面右上方；素材镜像统一受光，树木/长椅的地面投影向左下延伸。窗户与灯笼独立提供局部暖光。 |
| 远近层次 | 远山对比低、偏空气色；中山保留岩面；近处林丘以冷绿压住山脚；湖面降低倒影对比；近景材质与轮廓最清晰。 |
| 材质 | 木纹跟随木板，屋瓦错缝，石块有面和缝，树冠保持成簇叶片与枝杈空隙，花朵按物种和距离变化，避免满屏随机噪声。 |
| 遮挡 | 岸地先于小屋/树木；长椅支撑与坐垫先于角色，背靠条板后于角色；花丛/猫咪与望远镜接地，不把人物最后贴到全部前景上。 |
| 动态 | 静态构图先成立，再加四组轻摆花、不同相位叶梢、4缕烟、最多6片花瓣／5只萤火虫和少量水纹；减少特效时不降低静态纹理精度。 |
| 性能 | 四时段背景和改色材质缓存；逐帧只做小图层合成与有限水纹；山体只缓存有用的顶部，不在每帧重着色或重建纹理。 |

## 本轮刻意保留的边界

不重做整个庄园，不改故事、服装价格、糖果玩法、音乐、星星收藏或存档字段；不改流星雨轨迹和节奏。湖畔动作以温柔、克制为目标，不用增加亮点数量遮掩背景。

尚可继续精修的美术问题留待验收：极窄屏幕中两侧树木仍会自然出画；小船屋、望远镜与主小屋分别来自原创和授权纹理，材质笔触还有进一步统一的空间；坐姿先覆盖背面及换装配色，尚未为每套服装补齐独立刺绣和褶皱；手机内核模拟不等同于真实低端手机的GPU和屏幕色彩表现。
