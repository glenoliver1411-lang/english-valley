# Hard quality gate for visual acceptance

Check each item in real browser gameplay screenshots, never in a standalone art viewer:

- [ ] Final displayed flower-shop image actually uses original PNG. No procedural replacement.
- [ ] Uniform image scale; image does not warp, stretch or become soft due to inappropriate scaling.
- [ ] Strong identifiable architecture is visible: tall glass window, staircase, mezzanine, flower displays, checkout counter.
- [ ] Player remains visually proportionate to counters, floor and architecture; feet contact floor and shadow is grounded.
- [ ] Touch navigation works and character does not walk through counter/flower pots/rails.
- [ ] Interaction triggers work in original florist economy; no duplicated furniture drawn over its painted counterpart.
- [ ] New art is not blocked by permanent giant UI overlays.
- [ ] Main preview and stable production remain unchanged; separate preview published.
- [ ] Saved games remain backwards compatible (no reset) and offline works on a fresh installed preview and after reload.
- [ ] Captures compare old gameplay vs new actual game under same viewport and document precise limitations.
